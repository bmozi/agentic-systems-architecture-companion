# Role-Based Paths

An agent is not valuable because it appears intelligent. Its value comes from
useful work performed through authority, boundaries, and evidence people can
defend. Choose the path closest to your accountability.

## Agent or application developer

**What this unlocks:** an agent that can use real capabilities without one
model session becoming the authority, state store, or audit trail.

1. Complete the [thirty-minute start](START-HERE.md).
2. Define one callable path in the
   [Governed Tool Contract](governed-tool-contract.md).
3. Bound accumulated consequence with the
   [Action Budget](action-budget-and-blast-radius.md).

Leave with: one enforceable action boundary and one receipt path.

## Architect, security, or operations lead

**What this unlocks:** visible delegation across models, APIs, MCP tools,
events, workflows, memory, and people.

1. Complete the [Agent Authority Map](agent-authority-map.md).
2. Trace memory influence in the
   [Memory and Provenance Record](memory-and-provenance-record.md).
3. Connect stop, containment, reconstruction, and re-entry through the
   [Incident Readiness Plan](agentic-incident-readiness-plan.md).

Leave with: a boundary architecture that can survive model or framework change.

## Product or program manager

**What this unlocks:** a useful delegation roadmap based on work and evidence,
not feature theater or a leap directly to broad autonomy.

1. Name the work people want to stop doing and the consequence if it is wrong.
2. Use the [Value and Evidence Ledger](VALUE-AND-EVIDENCE-LEDGER.md) to define a
   baseline, bounded action, and decision evidence.
3. Expand only through the [Autonomy Evidence Gate](autonomy-evidence-gate.md).

Leave with: a supervised pilot and an evidence-based expansion rule.

## Executive or authority owner

**What this unlocks:** a defensible answer to what the organization may delegate
and which powers, obligations, and residual risks remain human or institutional.

1. Read the [Executive Decision Brief](EXECUTIVE-DECISION-BRIEF.md).
2. Require an authority source, enforcement point, blast-radius limit,
   revocation path, evidence owner, and reconsideration trigger.
3. Decide whether to observe, advise, recommend, act under approval, or act
   within a bounded autonomous scope.

Leave with: a specific delegation decision—not approval of “the agent.”

## Cross-role handoff

Ask someone outside the implementation team to explain what the agent may do,
whose authority it uses, when it must stop, and how one consequence is proved.
If they describe personality or intelligence instead, the operating contract
is not yet clear.
