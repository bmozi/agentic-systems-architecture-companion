# Pilot and Usability Route

Use this route to test whether practitioners can bound and review an agentic
action without the author supplying missing decisions.

## Status ladder

Use only the highest supported label: **Prepared**, **Piloted**, **Revised**,
**Repeated**, or **Practitioner-tested**. This reader-value layer is currently
**Prepared**. Existing Glasswing materials and blank logs do not establish a
completed result.

## First pilot

1. Review [testing/README.md](testing/README.md) and select a protocol-approved
   scenario version.
2. Give participants the [Failure Lab](FAILURE-LAB.md) and only the linked
   companion assets.
3. Include an implementation role, an authority or business owner, and an
   outside-role reader.
4. Observe whether participants identify the principal, withheld power,
   enforcement point, durable owner, effect-aware budget, stop path, and proof.
5. Record time to first useful artifact, confusion, unsafe scope expansion, and
   unresolved decisions.
6. Record only sessions that occurred in
   [Practitioner Test Logs](PRACTITIONER-TEST-LOGS.md).

## No-result rule

Repository validation, an author walkthrough, a constructed example, or an
unrun protocol is not practitioner evidence. Preserve negative and boundary
findings with successes.
